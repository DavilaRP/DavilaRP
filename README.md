Sou estudante de Ciência da Computação na Universidade Federal do Rio Grande do Sul (UFRGS) e tenho interesse por programação e desenvolvimento de software.

Atualmente estou construindo minha base em programação aos poucos, estudando lógica, algoritmos e os fundamentos da computação. Acredito que uma boa formação começa pelo domínio dos conceitos essenciais, e este perfil acompanha esse processo.

Este GitHub será utilizado principalmente para armazenar as atividades, exercícios e projetos que desenvolver ao longo dos estudos, desde os primeiros contatos com programação até trabalhos da graduação e projetos pessoais.
